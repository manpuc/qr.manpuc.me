## Direction contract

THESIS: Transform QR Maker from soft, generic iOS glassmorphism into Monolith UI essentialism: strict 0px structural geometry, 1px hairline borders, high-contrast monospace metrics, and pure monochromatic focus where only the generated QR code and actionable alerts carry purposeful color.

OWN-WORLD: Monolith UI palette (Light: #ffffff canvas, #000000 text, #e5e5e5 borders, #f4f4f5 muted/accent surfaces; Dark: #000000 canvas, #ffffff text, #27272a borders, #18181b muted). Sharp 0px corners on containers, inputs, buttons, and select boxes. 1px borders everywhere. Floating meta-actions (theme/lang switches and utility buttons) using 9999px rounded-full for layer decoupling. 150ms snappy transitions (`ease-[cubic-bezier(0.16,1,0.3,1)]`).

STORY: The user lands on an austere, distraction-free laboratory for QR code crafting. Entering a URL/text gives instant, reactive visual feedback with an industrial-grade preview and an unambiguous contrast readiness meter. Configuration options are organized cleanly in borderless/hairline sections. Downloads (PNG/SVG) and sharing trigger in one click with tactile, zero-lag micro-interactions.

FIRST VIEWPORT: Top floating header with minimalist brand title ("QR MAKER" / MANPUC) and status indicators, followed by a balanced two-column workbench (Desktop) or stacked focus stream (Mobile): Left pane holds the organized parameter matrix (Data, Dots, Dimensions, Colors, Center Icon/Emoji); Right pane holds the sticky preview frame with hairline technical bounding box, live contrast validation badge, and primary action bar.

FORM: Monolith UI Industrial Essentialism, adapted directly from char.manpuc.me and ui.manpuc.me design system rules.
seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
